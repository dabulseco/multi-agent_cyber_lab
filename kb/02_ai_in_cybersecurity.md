# AI in Cybersecurity

## Defensive use cases
- alert triage
- log summarization
- anomaly detection assistance
- report drafting
- malware family clustering
- phishing review

## Offensive use cases
- phishing generation
- social engineering personalization
- code assistance for malicious scripting
- rapid adaptation of attacker content

Students should understand both sides:
AI can scale defenders, but it can also scale attackers.
