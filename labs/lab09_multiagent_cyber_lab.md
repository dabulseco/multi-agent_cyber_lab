# Lab 09: Multi-Agent Cybersecurity Investigation

## Goal
Use the local multi-agent lab environment to investigate a scenario and critique the crew output.

## Steps
1. Select a scenario
2. Review all artifacts before running the crew
3. Build or refresh the RAG index
4. Run the crew
5. Export the final report
6. Write a reflection that answers:
   - Which findings were strongly supported by evidence?
   - Which findings were only weakly supported?
   - Which agent was most cautious?
   - What would you verify next as a human analyst?

## Deliverable
Submit:
- exported incident report
- one-page critique
- corrected human-written summary
